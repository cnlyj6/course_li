# 副业起步方案（优先 3 个）

结合你现有能力（Python、机器学习作业、会用 Git / Colab），下面 3 个相对**见钱快、启动成本低**。

目标假设：
- 每周可投入：10–15 小时
- 短期目标：先赚到第一笔 300–1000 元
- 不露脸也可做

---

## 方案 A：AI / 自动化小单（最推荐）

### 做什么
帮个人或小商家做“立刻能用”的小工具，不接大项目：

- Excel / 表格自动整理、去重、分类
- 用 ChatGPT / API 做客服话术、内容初稿、简历润色流程
- 微信/网页表单收集后自动汇总
- 简单爬虫（公开网页信息整理）
- Colab 脚本：批量处理文本、图片描述、数据清洗

### 为什么适合你
你已经有 ML / notebook 基础，这类单子技术门槛刚好，交付周期短（1–3 天）。

### 报价参考
- 超小单：150–300 元（1 天内）
- 常规小单：400–800 元（2–3 天）
- 带简单部署/说明文档：800–1500 元

### 怎么获客（本周就能做）
1. 朋友圈 / 同学群发一句话：
   > 接 AI 小工具 / 表格自动化 / 脚本代写，24–48 小时交付，有样例可看
2. 发到：电鸭社区、即刻、小红书（搜“自动化”“效率工具”相关话题）
3. 准备 2 个免费样例当作品：
   - 简历关键词优化脚本
   - Excel 销售表自动汇总脚本

### 本周行动清单
- [ ] 做 1 个可演示的 Excel 自动化样例
- [ ] 写 1 段 50 字接单介绍
- [ ] 在 3 个群/平台发出去
- [ ] 先接 1 单，哪怕只收 200 元练交付

---

## 方案 B：Python / 作业 / 面试陪练（成交最快）

### 做什么
一对一辅导，不做代写争议内容，主打“陪学 + 讲解”：

- Python 入门答疑
- 机器学习作业思路讲解（概念、代码报错）
- 简历项目讲解 / 模拟面试
- Colab / Git 使用辅导

### 为什么适合你
仓库里本身就有 HW3 / HW4 / Finetuning 等内容，说明你刚学完或正在学，讲给后来者很自然。

### 报价参考
- 体验课：49–99 元 / 45 分钟
- 正价：128–198 元 / 小时
- 套餐：3 次课 300–500 元

### 怎么获客
1. 同学群、实验室群、考研/转码群
2. 小红书发笔记：`我是怎么弄懂 Transformer 的`、`Colab 报错高频解决`
3. 先免费做 1 次体验，换评价，再收费

### 本周行动清单
- [ ] 选定 1 个主打主题（建议：Python 报错排查 或 ML 作业讲解）
- [ ] 写 3 条短内容（可发小红书/朋友圈）
- [ ] 约 2 个熟人试讲，收反馈
- [ ] 定好体验价并开始接

---

## 方案 C：技术兼职修 bug / 小功能（单价更高）

### 做什么
- 修网站小 bug
- 加一个小功能（登录页、表单、后台导出）
- 帮人部署简单服务
- 帮人整理 GitHub 项目 README / 脚本

### 报价参考
- 修小 bug：200–500 元
- 小功能：800–2000 元
- 注意：先收 30%–50% 定金，范围写清楚

### 获客渠道
- 程序员客栈、电鸭、Upwork（英文单）
- 朋友介绍（转化率最高）

### 风险提醒
大项目、需求不清、对方“先做完再谈钱”的单子先别接。

---

## 建议优先级

| 排序 | 方案 | 见钱速度 | 难度 | 建议 |
|------|------|----------|------|------|
| 1 | A. AI/自动化小单 | 快 | 中 | 主攻 |
| 2 | B. 一对一陪练 | 最快 | 低 | 同步做 |
| 3 | C. 修 bug/小功能 | 中 | 中高 | 有单再接 |

一句话策略：

> **用方案 B 快速赚第一笔，用方案 A 做可复制收入。**

## 7 天执行计划

### Day 1–2
- 确定主打：`AI 表格/文本自动化`
- 做 1 个样例（可用你熟悉的 Python）
- 写接单文案

### Day 3–4
- 发出接单信息到至少 5 个地方
- 同步发 2 条陪练内容
- 回复所有咨询，当天给报价

### Day 5–7
- 完成第一单交付
- 要评价/转介绍
- 复盘：哪类咨询最多，下周只做那一类

